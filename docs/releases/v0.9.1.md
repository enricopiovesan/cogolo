# Traverse v0.9.1

Released 2026-08-09.

Traverse v0.9.1 advances the governed capability-authoring and publishing path.
It also makes emitted events from executable capabilities part of the live local
execution path rather than relying on the retired output-JSON convention.

## Highlights

- The CLI supports the capability package workflow: scaffold, inspect, validate,
  and publish executable WASM capabilities.
- Capability publication writes artifact metadata with registry records and fails
  when a referenced persona cannot be resolved, including in dry-run mode.
- `LocalExecutor` carries real capability-emitted events through the runtime.
- Contract-surface coverage is enforced at publish time so declared contract
  behavior is backed by executable use cases.
- Five governed examples are available with end-to-end smoke coverage:
  `core.authorize`, `core.process-comment`, `core.transition-action-status`,
  `core.assign-ownership`, and `core.validate-action-item`.
- The published CLI package includes its generated protobuf source.

## Upgrade notes

The binary remains `traverse-cli`; use the capability authoring and publishing
guides for the current package flow. Consumers that previously interpreted
capability output JSON as runtime events should consume the structured emitted
events supplied by the runtime instead.
